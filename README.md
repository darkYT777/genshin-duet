# DUET · 원신 합주 도우미

싱글 연습과 친구와의 합주를 돕는 Windows 오버레이 앱입니다.

[최신 다운로드와 변경 사항](https://github.com/darkYT777/genshin-duet/releases/latest)

배포 ZIP을 압축 해제하고 Rhythm.exe를 실행하세요. Windows 10/11 64비트용이며 .NET을 따로 설치할 필요가 없습니다.
DUET 22 이상은 앱의 ‘업데이트’에서 새 버전을 받을 수 있습니다. 설정과 MySheets 폴더는 유지됩니다.

## DUET 24

- 마이페이지·업데이트 버튼이 로고와 겹치던 첫 실행 배치를 수정했습니다. DUET 22/23에서 버튼이 가려지면 창 크기를 조금 바꾼 뒤 업데이트를 누르세요.
- 친구끼리 쓰는 공유 악보 보관함. 호스트에 연결해 목록을 보고 미리듣고 받거나, 친구도 악보를 올릴 수 있습니다. 공유 보관함은 호스트의 SharedSheets에 남습니다.
- 호스트가 공유 악보를 방에 적용하면 참가자에게 자동 적용됩니다. 받은 악보로 방에서 나가 혼자 연습할 수도 있습니다.
- 직접 입력·붙여넣기·텍스트 파일로 악보 만들기. ADH는 화음, 띄어쓰기는 다음 칸, -는 한 칸 쉼입니다. BPM과 칸 길이·악기·여러 파트를 설정하고 미리듣기·저장·연습이 가능합니다.
- 연습 화면의 도구를 미리듣기·공유 악보·텍스트 악보로 정리했습니다. 내 악보 저장과 관리는 마이페이지에 있습니다.

공유 목록에는 호스트도 DUET 24 이상이어야 합니다. 별도 공개 서버는 필요하지 않습니다. 호스트가 앱을 끄면 목록 접속은 끝나지만 친구가 받아 둔 악보는 계속 남습니다.

## DUET 23

- 프로필과 내 악보를 주 창의 마이페이지로 통합. 캐릭터 선택, 닉네임 저장, 악보 검색·보관·미리듣기·불러오기.
- 놓친 음을 다음 몇 화음 뒤 지우거나 서서히 사라지게 하는 옵션. 기존 즉시 사라짐·입력까지 유지도 선택 가능.
- 위쪽 악보 아래의 세로 3줄 악보. 화음을 한 칸에 묶고 현재 화음을 네모로 강조. 현재 줄을 가운데에 유지.
- 다음 음 전용 색상 선택과 색상 코드·팔레트.
- 템포 전환과 음 입력에 따라 위쪽 악보의 간격이 갑자기 바뀌던 문제 수정.

합주방에 들어오면 호스트의 악보와 트랙이 자동 적용됩니다. 혼자 연습에서는 모든 파트·내 파트·다른 파트·특정 파트 자동연주를 선택할 수 있습니다.
미리듣기와 반주에는 원신 바람의 노래 하프 샘플을 사용합니다. 원신 키 자동연주는 싱글에서 원신 창이 활성화된 동안 작동합니다. Esc 또는 F8로 정지하세요.

설정 위치: 지금 칠 음(놓친 음), 다음·연속음(다음 음 색상), 세로 3줄 악보(새 악보 표시).
공개 배포에는 개인 설정과 악보를 포함하지 않습니다. 악보는 직접 불러오거나 합주방에서 받습니다.
