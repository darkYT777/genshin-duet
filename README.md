# DUET · 원신 합주 도우미

싱글 연습과 친구와의 합주를 돕는 Windows 오버레이 앱입니다.

[최신 다운로드와 변경 사항](https://github.com/darkYT777/genshin-duet/releases/latest)

배포 ZIP을 압축 해제하고 Rhythm.exe를 실행하세요. Windows 10/11 64비트용이며 .NET을 따로 설치할 필요가 없습니다.
DUET 22 이상은 앱의 ‘업데이트’에서 새 버전을 받을 수 있습니다. 설정과 MySheets 폴더는 유지됩니다.

## DUET 28.1.4

- 싱글 재생 버튼 옆 ‘구간 연습’에서 시작·끝을 정합니다. 틀린 음이나 놓친 음이 생기면 준비 박자 뒤 다시 도전합니다.
- 실수 후 돌아갈 곳은 지정한 지점 / 틀린 마디 시작 / 곡 처음 중에서 고릅니다. 텍스트는 저장된 마디 길이를 사용하며, 마디 정보가 없는 악보는 박자 수와 첫 마디 시각을 맞춥니다.
- 자동 진행과 입력 연습에서 쓰며 실수 조건·놓침 허용 시간·준비 박자·성공 뒤 멈춤/반복을 조절합니다. 되감기는 반주와 입력 표시도 정리하고 유지 키를 해제합니다. 창 전환은 일시정지하며 합주방에는 적용하지 않습니다.
- 텍스트의 파트별 악기와 기본 키 배치를 정리하고 미리듣기의 중복 상단 음색을 없앴습니다. 작은 창에서는 트랙 악기 선택을 아래 줄로 옮겨 겹침을 피합니다.
- 미리듣기 상단 ‘음 길이 → 다음 음까지 유지’는 해당 파트의 다음 음까지 소리를 이어줍니다. 첫 줄 마지막 W를 다음 줄 첫 Q까지 유지할 때 악보 표기는 그대로 쓰면 됩니다. 마디 뒤 쉼도 포함합니다.
- 미리듣기의 악보 길이 / 자동 / 다음 음 유지 중에서 고릅니다. 자동은 텍스트 호른·보댜니차·현악기에 적용하고 MIDI의 원래 길이는 보존합니다. 하프처럼 뜯는 악기는 원래 감쇠하는 소리로 들립니다.

## DUET 28.1.3

- 텍스트 악보 만들기·수정에서 `- 한 개 쉼`과 공백 간격 길이를 따로 조절합니다. 기본 간격의 배율과 BPM에 따른 실제 초, `Q-W` 예시를 함께 표시합니다.
- 공백 묶음 길이에 비례 / 같은 간격 / 공백 1개씩 계산을 고릅니다. 한 개씩 계산하면 앞쪽 공백과 대시 뒤 공백도 쉼으로 읽습니다. 마디 길이와 마디 뒤 쉼은 별도 설정입니다.
- 두 값은 모든 파트에 적용하고 악보와 함께 저장합니다. 내 악보 재편집과 방·친구 공유에도 유지하며 기존 악보는 이전 박자를 유지합니다.
- A/B 파트 탭 바로 아래에서 기본 악기를 미리 고릅니다. 하프·호른·보댜니차 등을 파트마다 지정하면 미리듣기·반주·저장에 적용하고 2줄/3줄 키 배치를 표시합니다.
- 입력창의 줄바꿈과 작은 창에서 잘리던 도구 버튼도 수정했습니다.

## DUET 28.1.2

- 길게 누르기 안내를 음 가이드 테두리의 남은 시간 게이지로 바꿨습니다. 원 둘레가 점점 줄어들며 끝나면 사라집니다. 별도의 길게 누르기 악보와 아래 시간 막대는 제거했습니다.
- 설정 → 길게 누르기 → 테두리 게이지에서 켜고 끕니다. 2줄·3줄 악기와 유지 길이 설정을 따르며, 누른 음이 지워져도 남은 길이는 볼 수 있습니다.
- 3줄 악보의 네모 박스는 다음 화음까지의 실제 시간으로 이동합니다. 짧은 간격은 빠르게, 긴 간격은 천천히 움직이고 재생 속도 변경도 따라갑니다.
- 줄 바꿈은 오른쪽에서 나가 왼쪽으로 이어집니다. 일시정지와 입력 대기에서는 멈추고, 위치를 바꾸면 즉시 해당 시각에 맞춥니다.

## DUET 28.1.1

- 업데이트와 패치노트의 기본 흰색 스크롤바를 두 테마에 맞는 얇은 스크롤바로 바꿨습니다. 본문 휠·드래그·키보드 스크롤과 버전 목록을 정리했습니다.
- 재생 버튼 오른쪽의 ‘싱크 ms’로 반주와 원신 소리 타이밍을 맞춥니다. 반주가 먼저 들리면 +, 늦게 들리면 −로 조절하며 속도가 달라도 실제 밀리초 기준입니다. 원신 키 입력과 악보 시계는 유지합니다.
- 같은 위치의 ‘길게 누르기’에서 자동 / 짧게 누르기 / 다음 음까지 유지를 고릅니다. 자동은 선택한 호른과 보댜니차를 다음 음까지 유지합니다.
- 같은 키 연타에 키를 떼는 간격을 확보하고, 입력 연습에서 마지막 긴 음과 지연된 반주가 바로 잘리던 문제를 고쳤습니다. 정지·일시정지에서는 예약된 소리와 입력도 취소합니다.

## DUET 28.1

- 선택한 보댜니차를 자동으로 2줄 QWERTYU / ASDFGHJ에 맞춥니다. 저장된 3줄 정보보다 선택 악기가 우선하며 직접 고른 배치는 유지됩니다.
- 반주와 내 파트 자동연주를 독립 스위치로 나눴습니다. B 담당이면 A·C·D는 앱 소리로 반주하고 B만 원신 키로 입력합니다.
- 내 파트 변경, 길게 누르기, 입력 연습, 창 전환과 정지에서도 두 역할을 분리합니다. 이전 동시 재생 설정은 새 방식으로 이전합니다.

## DUET 28

- 설정을 연주·음표 표시·악보·앱으로 묶고 검색을 추가했습니다. 일치하는 항목은 강조하며 Ctrl+F로 검색창에 바로 이동합니다.
- 설정 변경은 자동 저장됩니다. 숫자와 슬라이더도 저장하며, 연속 조절은 묶어 저장해 불필요한 파일 쓰기를 줄였습니다. 완료 버튼과 저장 상태를 고정했습니다.
- 두 테마의 버튼·입력창·드롭다운·스위치·슬라이더를 다듬었습니다. 선택·호버·눌림·비활성·키보드 포커스를 구분하고 여러 줄 입력창의 내용 공간을 수정했습니다.
- 드롭다운 체크는 선택한 항목에만 표시합니다. 마우스를 올리는 항목은 배경만 강조하도록 수정했습니다.
- 3줄 악보에서 현재 마디의 남은 음은 밝은 흰색, 지나간 음과 다음 줄은 낮은 밝기로 표시합니다. 네모 박스가 다음 음으로 부드럽게 이동하며 설정에서 이동 효과와 흰색 강조를 각각 고를 수 있습니다.
- 반주 방식에 ‘반주 소리 + 원신 자동연주’를 추가했습니다. 선택한 파트의 앱 소리와 원신 키 입력이 같은 박자에 함께 나오며, 게임 창을 벗어나면 키를 해제하고 앱 소리는 계속 재생합니다. 일시정지·Esc는 둘 다 정지합니다.
- 내 악보에 다운로드·즐겨찾기·정렬과 지역·인원 필터를 추가했습니다. 모든 파트와 파트별 악기, 상세정보를 파일에 함께 보관합니다.
- 마이페이지의 ‘내 악보’와 ‘공개 악보’를 나눴습니다. 기본 제공 악보는 공개 악보에 있으며, 내 악보에 추가하면 원본을 보존한 채 수정할 수 있습니다. 친구 공유는 별도 버튼으로 열며 저장한 개인 악보는 자동으로 공유되지 않습니다.
- 악보 상세정보에서 지역·작곡·편곡·원본 영상·악보 링크·설명을 수정할 수 있습니다. 공유와 방 악보에도 출처가 유지됩니다.
- Animuz Anime Piano의 공개 MIDI 4곡을 기본 악보로 추가했습니다. I Loved You, Nod-Krai, Nahida Demo, Furina Demo의 솔로판과 2인판, Furina의 3인판까지 총 9개입니다.
- 합주판은 원본의 음과 시간을 유지하며 파트를 나눈 DUET 연습 편성입니다. 원 제작자의 별도 합주판과 구분해 표시합니다. 각 악보의 상세정보에 제작자와 원본 링크를 넣었습니다.
- 친구 주소록에서 닉네임·캐릭터·호스트 주소를 추가·수정·삭제하고 접속 준비를 할 수 있습니다. 암호는 저장하지 않으며, 방을 열 때만 호스트 앱을 켜 두면 됩니다.
- 방 만들기·참가의 선택 상태, 트랙의 파트 배지와 구분선, 긴 이름 표시와 주요 버튼 설명을 정리했습니다. 재생 막대의 표시 위치와 마우스 입력을 맞췄습니다.

친구 주소록은 마이페이지에 있습니다. 온라인 상태·오프라인 초대·상시 공개방은 제공하지 않습니다. 원격 접속에는 기존 호스트 주소 연결 환경이 필요합니다.

## DUET 27

- 트랙마다 삭제와 자동연주 스위치, 반주 악기 선택을 추가했습니다. 2파트에서 1파트로 줄일 수 있습니다.
- 미리듣기도 파트마다 악기를 고릅니다. 악기 선택은 악보 파일에 함께 저장되어 방 참가자에게도 전달됩니다.
- 내 악보 삭제와 제목 수정 저장을 고쳤습니다. 삭제와 수정 전 파일은 백업합니다.
- 설정 메뉴의 가로 스크롤과 잘림을 고쳤습니다. 설정 저장 초기화 오류를 피하는 저장 방식과 백업을 추가했습니다.
- 4파트 시트의 악기, 음 길이와 시간을 읽으며 호른의 2줄 배치를 자동으로 적용합니다. 연습 화면에서 배치를 바로 바꾸며 위치를 불러옵니다.
- 연타 막대와 입력 인정 시점을 맞췄습니다. 길게 누르는 음의 남은 시간과 길이를 가이드와 악보에 표시합니다.
- 하프와 두 음을 담은 새 앱 아이콘을 적용했습니다.

호스트와 참가자 모두 27로 업데이트하면 파트별 악기와 1트랙 방을 함께 사용할 수 있습니다.

## DUET 26

- 여러 트랙 오버레이 표시와 입력 검사 최적화. 화면을 재사용하며 2줄 악기를 직접 고르면 배치를 유지하고 3줄 악보의 현재 화음 색상 강조를 유지합니다.
- 앱 안에서 버전별 패치노트 보기. 업데이트 화면과 설정 → 앱 업데이트에서 열며 최신 버전이어도 읽을 수 있습니다. 불러온 기록은 오프라인에서도 보관하고 업데이트 설치 뒤 새 내용을 엽니다.
- 기존 하프를 포함한 9가지 악기 소리: Floral Zither, Nightwind Horn, Harmonic Keys, Vintage Lyre, Ukulele, Lingering Euphonia, Leaping Spirit Piano, Vodyanitsa. 미리듣기와 앱 반주에서 트랙의 악기를 자동으로 선택하거나 음색을 직접 고릅니다.
- 여러 악기를 섞어 재생할 때 활성 음만 계산합니다. 8악기 출력 검사에서 버퍼 끊김 0회를 확인했습니다. 사람의 청취에 따른 음질 평가는 별도입니다.

## DUET 25

- 텍스트 듀엣의 공백 길이와 쉬는 시간을 반영합니다. 같은 줄을 같은 마디로 맞춰 음이 적은 파트의 빈 구간을 유지합니다. 마디 길이와 마디 사이 쉼도 곡에 맞춰 조절합니다.
- 저장한 텍스트 악보의 원문·박자·악기 설정을 다시 수정합니다. 내 악보의 수정 버튼, 같은 파일 저장과 이전 파일 백업을 지원합니다.
- 게임 음 버튼 위의 가이드를 끄고 악보만 볼 수 있습니다. 세로 악보는 설정 → 세로 3줄 악보에서 켭니다.
- 직접 연주와 원신 키 자동연주를 다음 음까지 길게 유지하는 옵션을 각각 제공합니다. 정지·창 전환·Esc에서 유지가 풀립니다. 앱 하프 반주 소리에는 적용하지 않습니다.
- 마이페이지 복귀 버튼의 가림과 텍스트 악보 제목 잘림을 수정했습니다.

## DUET 24

- 마이페이지·업데이트 버튼이 로고와 겹치던 첫 실행 배치를 수정했습니다. DUET 22/23에서 버튼이 가려지면 창 크기를 조금 바꾼 뒤 업데이트를 누르세요.
- 친구끼리 쓰는 공유 악보 보관함. 호스트에 연결해 목록을 보고 미리듣고 받거나, 친구도 악보를 올릴 수 있습니다. 공유 보관함은 호스트의 SharedSheets에 남습니다.
- 호스트가 공유 악보를 방에 적용하면 참가자에게 자동 적용됩니다. 받은 악보로 방에서 나가 혼자 연습할 수도 있습니다.
- 직접 입력·붙여넣기·텍스트 파일로 악보 만들기. ADH는 화음, 띄어쓰기는 다음 칸, -는 한 칸 쉼입니다. BPM과 칸 길이·악기·여러 파트를 설정하고 미리듣기·저장·연습이 가능합니다.
- 연습 화면의 도구를 미리듣기·공유 악보·텍스트 악보로 정리했습니다. 내 악보 저장과 관리는 마이페이지에 있습니다.

공유 목록에는 호스트도 DUET 24 이상이어야 합니다. 별도 공개 서버는 필요하지 않습니다. 호스트가 앱을 끄면 목록 접속은 끝나지만 친구가 받아 둔 악보는 계속 남습니다.

## DUET 23

- 프로필과 내 악보를 주 창의 마이페이지로 통합. 캐릭터 선택, 닉네임 저장, 악보 검색·보관·미리듣기·불러오기.
- 놓친 음을 다음 몇 화음 뒤 지우거나 서서히 사라지게 하는 옵션. 기존 즉시 사라짐·입력까지 유지도 선택 가능.
- 위쪽 악보 아래의 세로 3줄 악보. 화음을 한 칸에 묶고 현재 화음을 네모로 강조. 현재 줄을 가운데에 유지.
- 다음 음 전용 색상 선택과 색상 코드·팔레트.
- 템포 전환과 음 입력에 따라 위쪽 악보의 간격이 갑자기 바뀌던 문제 수정.
