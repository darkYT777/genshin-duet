# DUET · 원신 합주 도우미

싱글 연습과 친구와의 합주를 돕는 Windows 오버레이 앱입니다.

[다운로드와 변경 사항 보기](https://github.com/darkYT777/genshin-duet/releases)

배포 ZIP을 압축 해제하고 Rhythm.exe를 실행하세요. Windows 10/11 64비트용이며 .NET을 따로 설치할 필요가 없습니다.

## DUET 22

- 앱 실행 시 새 버전을 확인하고 검증 후 다운로드·설치합니다. 설정과 내 악보는 유지합니다.
- 방에 들어오면 호스트 악보와 트랙 구성을 자동으로 받아 적용합니다. 받은 악보는 내 악보에 보관합니다.
- 재생 버튼 오른쪽에서 반주·자동연주를 설정합니다. 다른 파트 모두 / 모든 파트 / 내 파트 / 특정 파트를 고릅니다.
- 앱 소리와 원신 키 자동연주를 선택합니다. 원신 키 자동연주는 싱글에서 원신 창이 활성화된 동안 작동합니다. Esc 또는 F8로 정지합니다.
- 미리듣기의 원신 바람의 노래 하프 샘플과 기존 합성음 선택.
- 위쪽 악보 가운데 정렬, 이후 음 표시, 드롭다운 휠 개선.

DUET 21 이하 사용자는 업데이트 기능이 들어간 DUET 22를 한 번 직접 받아 교체해야 합니다. 다음 버전부터는 앱의 ‘업데이트’를 사용하세요.

공개 배포 파일에 개인 설정과 악보는 포함하지 않습니다. 악보는 사용자가 직접 불러오거나 합주방에서 받습니다.
